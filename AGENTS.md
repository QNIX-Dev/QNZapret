# AGENTS.md

Все агенты, работающие в этом репозитории, обязаны сначала определить, в какой ветке они находятся, и в зависимости от этого прочитать соответствующие инструкции.

Обязательные правила входа в задачу:
1. Выполнить команду `git branch --show-current`, чтобы определить текущую ветку.
2. В зависимости от ветки:
   - Если ветка `quriee`: 
     Немедленно прочитать регламент внутри **`.qdocs/`**.
   - Если ветка `n1xflow`: 
     Немедленно прочитать регламент внутри **`.ndocs/`**.
3. Считать прочитанный регламент главным источником проектных стандартов по архитектуре, UX, QA и Git Flow.
4. Любые локальные упрощения, предположения или отклонения от регламента сначала явно согласовывать с пользователем.
5. Вся коммуникация и документация вне кода ведется на русском языке.
